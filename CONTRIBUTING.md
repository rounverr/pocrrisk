# Feedback and contribution policy

## English

RRISK is an experimental proof of concept published under the [MIT License](./LICENSE). It is not a production-ready risk management tool.

- **Issues are welcome:** Report a bug, documentation problem, or suggestion through [GitHub Issues](https://github.com/rounverr/pocrrisk/issues). Provide enough context to understand the report.
- **No external code contributions:** Please do not submit pull requests or patches to this repository. Rounver Corp. alone maintains and changes the official project. External pull requests will not be merged.
- **Independent use is allowed:** The MIT License allows anyone to use, modify, fork, and redistribute their own copies, including for commercial purposes, as long as the license conditions are respected. This policy applies only to contributions to the official repository.
- **No support commitment:** Issues may be reviewed at Rounver's discretion; a response, fix, or further development is not guaranteed.

Do not include private credentials or sensitive data in public issues.

## Español

RRISK es una prueba de concepto experimental publicada bajo la [Licencia MIT](./LICENSE). No es una herramienta de gestión de riesgos lista para producción.

- **Se aceptan Issues:** Se pueden informar errores, problemas de documentación o sugerencias mediante [GitHub Issues](https://github.com/rounverr/pocrrisk/issues). Incluir suficiente contexto para comprender el reporte.
- **No se aceptan contribuciones externas de código:** No enviar pull requests ni parches a este repositorio. Rounver Corp. mantiene y modifica exclusivamente el proyecto oficial. No se integrarán pull requests externos.
- **Se permite el uso independiente:** La Licencia MIT permite usar, modificar, bifurcar y redistribuir copias propias, incluso con fines comerciales, siempre que se cumplan las condiciones de la licencia. Esta política se refiere únicamente a las contribuciones al repositorio oficial.
- **Sin compromiso de soporte:** Rounver puede revisar los Issues a su criterio; no garantiza respuestas, correcciones ni nuevos desarrollos.

No publicar credenciales privadas ni datos sensibles en Issues públicos.
